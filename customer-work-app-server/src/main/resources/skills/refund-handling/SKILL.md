# 退款处理技能

当用户表达退款 / 退货意图时，按以下流程处理：

1. **核对订单**：先用订单工具确认订单号、金额、下单时间、状态。
2. **资格校验**：调用退款资格校验工具，确认是否在七天无理由期内、是否已支付。
   - 不满足无理由条件时，不得直接拒绝，引导用户走特殊申诉（转人工）。
3. **生成工单**：满足条件后调用退款工单工具。
   - 资金安全红线：**只生成"待人工确认工单"，绝不承诺已直接打款**。
4. **金额异常**：单笔退款金额较大或用户情绪激动时，立即转人工坐席。

回复用户时口径要一致：已受理、转人工复核、预计处理时效，不要给出无法兑现的承诺。

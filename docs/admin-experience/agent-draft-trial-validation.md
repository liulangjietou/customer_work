# 智能体草稿受控试用与发布检查

## 行为与职责

管理员可先保存个人草稿，再从编辑器或“我的草稿”打开受控试用。服务端复用 `AgentService.validateConfiguration` 校验草稿、冻结所选主备模型或路由策略、Skill 和知识库版本。独立 ReAct 会话只消费该快照；不修改正式智能体、工作区会话、全局工具实例或发布任务。

`AgentDraftTrialStore` 在独立事务内持久受理，成功受理者才检查请求配额并调用模型。同一试用标识与相同输入只恢复原回执；内容冲突拒绝。120 秒截止后无法确认终态的记录收敛为 UNKNOWN，不自动重放。已返回成功但终态写入响应不确定时，保留原标识继续查询，不改记模型失败。

试用控制器从登录与租户上下文获取身份，校验个人草稿归属，并根据新建或编辑草稿检查对应权限。浏览器提供的租户或用户字段不能改变归属。所有试用和发布检查响应设置 `Cache-Control: no-store`；同令牌重登、权限变化也会废弃旧操作回调。

发布检查入口要求同时拥有 `agent:view` 和 `eval:view`。只读事务在同一数据库快照中聚合当前正式配置、最新发布任务、评测门禁和冻结目标实例的 ACK；不发起评测、网络连通性探测或发布。渠道关联、任务及 ACK 显式使用精确租户条件，ACK 还要求修订和内容哈希精确一致。

## 执行边界

- 实际执行所选模型，支持主备或启用的路由。试用熔断状态独立；首分片后模型失败直接失败，避免将另一个模型的完整回答拼接到半段输出后。
- 知识库读取固定版本，托管知识使用现有文档 ACL；外部知识检索不完整时失败，不显示为正常未命中。Skill 只读取固定版本说明和精确路径的 UTF-8 文本附件，不执行脚本。
- 系统工具只允许已核实的纯计算 `devtoolbox`。MCP、脚本、业务写操作、子智能体、长期记忆及上下文压缩等不在此次试用范围，页面显示这些限制。
- 试用标记为 `EVALUATION`，保留调用主体、版本谱系及真实模型用量，不产生在线实验曝光。统计沿用现有每个 Acting 批次一段的口径：单 Skill 段归 SKILL；多个不同工具同轮调用保留全部工具名，合计耗时归 TOOL，不提供虚构的逐工具耗时。
- 发布检查分别显示 NOT_REQUIRED、实际门禁结论、投递状态和实例确认。只有当前候选匹配、任务 APPLIED 且所有非空冻结目标均已确认，才显示当前配置已确认。旧版本、无目标及缺少目标的旧记录不会显示为当前全部生效。
- 当前候选比较范围与现有发布器实际控制的字段一致。未被发布器控制的能力不能据此推断已在客服环境生效；试用回答完成也不等于质量评测或发布门禁通过。

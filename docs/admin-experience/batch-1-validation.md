## 缺陷复现与回归边界

- 三个图表原测试只验证主题与窗口，未覆盖容器尺寸；新增 ResizeObserver 尺寸、零尺寸、重复通知、卸载清理用例，先失败后修复。
- 列表错误过去只有即时提示，异步旧响应也能覆盖新查询；补首次失败、保留旧结果、重试、乱序响应浏览器用例。
- 评测切换类型失败时残留原类型数据；补失败测试并验证指标、用例和版本都切换到新类型的未知/失败状态。
- 知识源抽屉只监听打开状态；慢请求能覆盖下一个知识库。补延迟响应、关闭、打开另一个知识库和重新加载用例。
- SSE 旧测试只测试完整文本块解析，漏掉跨网络块的 CRLF 和 HTTP 200 业务错误。补传输层用例后修复。
- 历史直接读框架消息文本，缺少用户原文与运行材料边界。新原文元数据通过 AgentState JSON 往返验证；附件、普通聊天、编码、协作编码与旧记录均有回归。
- 编码 API 显式组装请求体，Store 的原文字段曾在这一层遗漏；Store mock 无法发现请求投影缺失。新增实际 API 封装用例，对非空与仅附件的空原文均先复现失败后修复。
- 框架缺少结束原因时默认返回 MODEL_STOP，不能据此断言旧消息完成。历史投影读取实际元数据；前端只将同轮明确 PROCESS 合入结果，旧记录保持 UNKNOWN。

125 条浏览器用例包含 41 条业务路由的挂载、390px 布局，以及关键页面的权限、焦点、错误恢复与工作区状态。它们不代表 41 个页面的全部业务写操作都已验收。夹具内有数据截图来自实际 Vue 组件，数据为隔离的测试响应，不作为真实模型或数据库写入证明。

# 客户消息受理与 H5 恢复契约

本次完成 CHAT-01 的客户消息入口、CHAT-03 的 H5 恢复及 H5-01 的输入受理状态。坐席端同标识回复、三栏协作、交接摘要和建议草稿继续独立实施，不能据此标记整个客服协作批次完成。

## 调用链和职责

- H5 `Chat.vue` → `useMessageDelivery` → `ChatSocket` → `/ws/user` → `ChatDispatchService`。
- 受理服务使用现有 `SessionLock` 和客服库事务，调用 `TicketService`、`ChatLogService`；提交后才调用 `ChatTurnService` 或向坐席转发。
- 回执丢失时，H5 查询 `/api/customer/user/sessions/{sessionId}/receipts/{clientMsgId}`。接口验证登录主体、租户和 `UserSessionGuard` 归属，只读本人输入，不调用模型。
- `ChatLogService` 负责生成受理消息号和访问存储；`WsFrame` 负责出站契约。草稿清理、错误恢复、历史合并属于 H5 会话交互层。
- 消息查询的三个 MyBatis 入口均传播数据访问失败，HTTP 返回失败状态，不能把连接故障伪装成空页或未受理。

## 受理与重复投递

客户端为一次输入生成一个 `clientMsgId`，重试沿用该标识和原内容。服务端将租户、会话、发送方类型、发送方及客户端标识编码为固定消息号，使用已有 `cw_chat_message.message_id` 唯一键。

| 情况 | 服务端行为 | H5 行为 |
|---|---|---|
| 浏览器连接无法写出 | 未发送命令 | 保留草稿和附件，不增加伪造的已发送气泡 |
| 输入与相关建单事务提交成功 | `chat_accepted` 带真实消息号、主键、会话和工单 | 气泡变为“已受理”；仅清理仍与原快照一致的草稿和原附件 |
| 同标识、同主体、同内容重复到达 | 回读同一保存记录，补发原回执 | 合并同一条消息，不再次调用模型或转发 |
| 同标识内容被改动 | 明确拒绝冲突 | 保留原记录，不能用新内容覆盖原请求 |
| 保存或提交状态不明确 | 带标识的 UNKNOWN 错误 | 保留输入，先查回执；查询失败时不重发 |
| 输入为空、超出 TEXT 字节容量或配额拒绝 | 明确 REJECTED，不预占标识 | 显示未受理，可核对后由用户重试 |

建单、用户消息、工单事件及 Outbox 使用同一数据库事务。跨实例重复投递最终由数据库唯一键和回滚裁决；进程内锁和 Redis 降级锁不构成跨实例唯一性证明。定向集成测试刻意移除锁，验证两实例同时读到空记录后的竞争。

受理只证明输入已保存，不证明 AI 回复或业务操作完成。进程在提交后、执行模型前退出时，重复投递仍只补回执；本次不增加后台执行恢复或自动重放工具。去重记录与现有聊天记录保持相同保留期限。

## 连接与页面状态

1. 草稿在收到回执前保留。用户已经输入的新内容、后来添加的附件不受旧回执清理影响；仅附件也可发送。
2. 待确认消息超时、断线或收到未知结果后，先查保存记录；仅明确查不到时，用户点击“核对并重试”才再次投递原命令。
3. 首次 WS 建立和每次重连均补拉消息及工单快照，覆盖初始 HTTP 请求与建立订阅之间的空隙。工单已关闭时恢复为只读。
4. 超过 50 条的恢复缺口按真实数据库游标继续补拉到已知边界；中途失败保留已展示消息。历史支持主动加载更早记录，加载失败可原地重试。
5. 实时消息与 HTTP 历史按业务消息号合并。时间戳和前端临时号不能作为数据库分页游标。
6. 断线或明确的回复失败会停止光标，把已收到片段收进可展开记录；不把半截文本标成完整回复，也不凭文本相似判断恢复成功。
7. 新出站增量、回复带会话、工单与原输入标识；客户端拒绝其他会话的增量。受理回执、坐席转发及异步出站帧在原租户作用域内发布。
8. 旧连接的迟到回调不能干扰新连接；离开页面后，迟到的初始化结果不能重新打开旧会话连接。

回执、消息历史及工单详情的 GET 查询不消耗提问额度，额度耗尽也可恢复；原身份认证、归属校验和写入口的配额判断保留。

## 兼容与边界

- 旧客户端不带 `clientMsgId` 时沿用首次处理；旧服务端没有受理协议时，新 H5 保留未知状态并允许查询核对，不把单次 WebSocket 写出视为保存成功。
- 本次没有数据库迁移；复用既有消息表、唯一键、事务和锁。JDBC 模式才具备跨重启的记录保留，内存模式用于本机与测试。
- 页内待确认记录与片段不跨页面关闭持久保存。关闭页面后长任务恢复不在本次首期范围。
- H5 附件沿用既有解析和消息拼装方式；来源版本、完整回复与原请求的持久对账及坐席端受理仍在后续范围内。
- 浏览器用例用明确隔离的 HTTP/WS 夹具验证真实 Vue 界面；数据库事务测试、鉴权切片测试分别证明对应后端边界，不能将它们描述成真实模型端到端调用。

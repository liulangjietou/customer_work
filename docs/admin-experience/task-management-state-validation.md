# Admin 业务状态验收：任务、渠道与项目

本批承接 PR #222，继续剩余清单第 8 项；不是 41 页全站验收完成声明。H5 真机综合验收按用户要求暂缓，第 9 项性能基线仍待正式测量。

## 调用链与已复现问题

| 调用方 | 下游与职责 | 影响场景及本批处理 |
|---|---|---|
| 租户编辑表单 | `/tenant` → `TenantService.update`，编码与生命周期归后端 | 保存期间重复操作、旧保存关闭新目标；使用既有 CRUD 锁与代次，保留准确 id、失败输入 |
| 定时任务表单与列表 | `/aiconfig/scheduled-task` → `ScheduledTaskService`，事件通知调度器 | current/size/records 在页面映射为共用分页模型；具体 cron、agentId 和启停含义保留 |
| 渠道机器人表单 | `/channel-robots` → `ChannelRobotService` | 复用 CRUD 生命周期；空 AppSecret 保留密文，微信安全模式校验与回调字段处理仍归页面与服务各自的契约 |
| Project 管理 | `/workspace/project` → `ProjectService` | 所有操作要求 workspace 权限，数据再受租户与角色数据范围限制；会话内容另有归属检查。没有凭空新增 project:view 或只读 CRUD 权限 |
| 配置版本、后台任务、Badcase 查询 | 各页的 page API → 既有 `usePagedList` | 失败保留旧数据并可重试；初次失败不显示空记录或零值，长任务结果在表格内收敛展示 |
| Skill 版本与上传 | `fetchSkillVersions` / `parseSkillUpload` | 旧目标返回不能覆盖新版本列表、正文或附属文件；版本失败提供原地重试 |
| SQL 参数与转换器子面板 | `SqlDefineController`：GET 要求 view，POST/PUT/DELETE 要求 edit | 只读仍可核对明细，写入口使用同一个 sql-define:edit 权限；本批没有声称后端存在越权 |
| 统一二进制导出 | `api/request.download` → Blob 下载链接 | 原先只隔离旧身份的错误提示，成功文件仍可触发下载；现在创建本地下载链接前检查发起登录，包含同令牌重登 |

这些表单原先手写状态管理，未消费已经验证的 `useCrudPage`。重复锁、目标代次与身份边界归公共 CRUD；字段映射、凭据留空、cron 和外部动作留在业务页面。本批没有重新设计后台领域模型。

## 测试缺口与复现

- 原 CRUD 测试没有覆盖上述手写表单。四个保存锁用例均先失败；旧保存用例最初在关闭动画期间误判，增加实际动画完成等待后四个均稳定失败，再修复为通过。
- 七页先出现查询失败后没有 `CrudLoadState`，同时有未消费异步错误；修复后数据、空、失败保留、重试、只读和 390px 范围通过。
- Skill 旧版本覆盖和 SQL 子面板写入口均先失败；上传用例修正实际名称定位后也先复现正文被旧结果覆盖。
- 下载使用真实 Axios 拦截器和可控网络响应。当前身份正向对照原本通过，换令牌与同令牌重登两个成功下载隔离用例原本失败，修复后 20 项请求单元测试全部通过。
- 截图复核发现渠道接入说明与长回调地址被卡片裁切；原整体 scrollWidth 断言看不到卡片内部的溢出。补了真实卡片内容边界用例并先失败，再局部允许说明文字换行。

浏览器夹具只证明真实 Vue 组件、请求体和交互状态。数据库验收使用独立随机双库、权威迁移、生产租户/数据范围插件和生产审计字段填充器；外部调度、会话存储及租户投递依赖按测试边界替换，不触发实际智能体或第三方渠道。

## 调用链与职责

| 入口 | 下游 | 检查边界 |
|---|---|---|
| 工作台密码复制、脚本生成、本地导入 | WorkbenchSiteManage → Workbench API → Site/Script Controller 与 Service；文件仅在浏览器读取和解析 | 原身份、请求锁、失败恢复、旧文件不覆盖新输入、实际下载文件字节 |
| 令牌列表、签发、吊销 | WorkbenchTokenDialog → TokenController → TokenService → Admin 令牌表 | 可重试查询、确认期间换身份、一次性明文、关闭后清除、哈希落库与有效期 |
| 菜单拖拽与发布 | MenuManage → MenuAdminController → PermissionService → Redis 锁与 Admin 菜单表；发布提升 MenuVersionHolder | 原生拖拽、错误回读、事务回滚、重登后重新加载、显式发布版本 |
| 配额维护与运行态 | SubjectQuotaGatewayProvider → 客服库等级表 → LevelProvider/Resolver/Guard → 命中表 | 等级修改刷新、超限计量和真实异步命中、数据库读取失败保留旧快照 |
| 轮播文件公开读取 | LoginImageStorageService → MinIO → LoginImagePublicController | 实际文件字节、删除后404、同桶私有附件禁止公开读取 |

后端存量实现通过新增的真实资源验收，不改其业务行为。前端复用 `useRowMutation`、`useQueryState`、`useAuthSubmissionScope`，表单自身管理打开和关闭的代次；身份、目标和请求状态分别由已有的对应层负责。无需新增全局状态框架。

## 原测试遗漏与失败证据

- 原工作台页面专项主要覆盖列表及公共 CRUD；密码读取、签发、吊销、下载和本地文件读取使用独立异步函数，未覆盖等待期间换身份、关闭或重新打开输入。
- 初始14条浏览器基线4通过、10失败：旧身份密码被复制、旧脚本触发下载、旧签发明文被展示、确认期间换身份仍发出吊销、脚本和令牌表单未锁定、查询故障没有重试入口、吊销等待未锁定，以及旧文件覆盖新草稿。菜单清理旧身份后没有重新加载，也由原生拖拽用例复现。
- 修复后14条全部通过。扩展相关回归26条中25通过，旧菜单测试误将身份切换后新发出的请求当成旧请求：网络记录显示旧请求没有响应，较晚请求收到旧夹具。现固定旧 Route/Request，并为新身份提供独立响应，保留原断言。扩大覆盖四类设置的旧身份用例后，29条全部通过。
- 各轮原始日志、退出码和浏览器追踪分别归档，不覆盖原失败证据。

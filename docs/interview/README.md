## 一、结论：北京 Java Agent 岗位主要考什么

调研中的三个观察：

1. **Java 岗位不只是把 Python 岗位换一门语言**。JD 通常同时要求 Java 基础扎实，并至少掌握一个 Java AI 框架
   （Spring AI / Spring AI Alibaba / LangChain4j / AgentScope Java）。LangChain、LangGraph 等 Python 框架大多列为加分项。
2. **2026 年新增的高频词是 MCP、上下文工程、Harness 和 Agent Skills**。公开的岗位观察提到，已有大厂把
   Agent Harness（上下文管理、工具执行、任务状态、调试与评测）单独列为一个工程方向。
3. **业务岗位常写“对接 CRM、客服系统、IM 和业务后台”**。项目里的工单状态机、转人工、退款审批和 CSAT
   正好对应这类要求，适合出场景题。

## 四、使用建议

- **面试官**：先用主问题开场，再用追问区分“读过代码”和“参与过设计”。减分回答可以用来识别背诵式作答。
  建议每期挑 3～4 道题，面试时间控制在 45 分钟左右。
- **候选人**：简历上写了这个项目，就要能讲清“为什么这样做”，而不只是“做了什么”。参考回答中的结论都附有代码位置，
  建议先读代码，再整理自己的说法。不要背类名；面试官真正想听的是：遇到了什么问题、有几种解法、最后选了哪种、代价是什么。
- **答题结构**（适用于所有题）：先给结论 → 说明问题本质 → 讲清取舍 → 用项目里的数据或事故举证 → 说明还没解决的边界。

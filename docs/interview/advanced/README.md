# Agent 开发 · 进阶篇（高级 / 资深岗位）

> 共 **10 期、108 题**，面向高级和资深 Agent 开发岗位，补充项目实战篇与通用篇没有覆盖的深度内容：
> 运行时工程、推理与训练、系统设计、线上排障与容量、数据类 Agent、评测统计、身份与合规、Java 深入、前沿趋势、技术领导力。
>
> 格式：每题包含**考察点**、**参考回答**、**追问**、**减分回答**。第 03 期是系统设计大题，每题改为给出“必答项”和“加分项”，
> 可以直接作为评分标准使用。

## 二、面试组织建议（高级 / 资深岗位）

| 轮次 | 时长 | 建议题目来源 |
|---|---|---|
| 技术一面 | 60 分钟 | 通用篇挑 4～5 题确认基础 + 项目实战篇（或候选人自己的项目）深挖 2～3 题 |
| 技术二面 | 60～90 分钟 | 进阶第 03 期系统设计 1 题 + 进阶第 04 期排障场景 2 题 + 进阶第 01 / 08 期各 1 题 |
| 交叉面 / 主管面 | 45～60 分钟 | 进阶第 06、07 期各 1 题 + 进阶第 10 期 2～3 题 |

- 全库题目的检索入口见 [../INDEX.md](../INDEX.md)。
- 法规、协议和前沿技术变化较快，相关题目只讲方向和判断方法，具体条款和数字以最新官方资料为准。

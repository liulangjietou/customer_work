### Q1 反转单链表。

**考察点**：指针操作、边界条件。

**思路**：用三个指针依次把每个节点的 `next` 指向前一个节点。

```java
class ListNode {
    int val;
    ListNode next;

    ListNode(int val) {
        this.val = val;
    }
}

class ReverseList {
    ListNode reverse(ListNode head) {
        ListNode prev = null;
        ListNode current = head;
        while (current != null) {
            ListNode next = current.next;
            current.next = prev;
            prev = current;
            current = next;
        }
        return prev;
    }
}
```

**复杂度**：时间 O(n)，空间 O(1)。

**追问**：*能否用递归实现？有什么风险？* 可以，但递归深度等于链表长度，链表很长时可能栈溢出。

**减分回答**：用额外的数组保存全部节点再重建链表。

### Q2 合并 K 个有序链表。

**考察点**：堆的使用、多路归并。

**思路**：把每个链表的头节点放入最小堆，每次取出最小的节点接到结果链表上，再把它的下一个节点放入堆中。

```java
class MergeKLists {
    ListNode merge(ListNode[] lists) {
        PriorityQueue<ListNode> heap = new PriorityQueue<>(Comparator.comparingInt((ListNode n) -> n.val));
        for (ListNode node : lists) {
            if (node != null) {
                heap.offer(node);
            }
        }
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        while (!heap.isEmpty()) {
            ListNode smallest = heap.poll();
            tail.next = smallest;
            tail = smallest;
            if (smallest.next != null) {
                heap.offer(smallest.next);
            }
        }
        return dummy.next;
    }
}
```

**复杂度**：时间 O(N log K)（N 为节点总数，K 为链表数），空间 O(K)。

**Agent 场景中的对应**：多个检索源（多个知识库、多个分片）各自返回按分数排好序的结果，需要合并成一个有序列表并取前 N 条。

**追问**：*还有其他解法吗？* 两两合并（分治），复杂度同样是 O(N log K)。

**减分回答**：把所有节点放进数组排序后重建链表（可以做，但说不出更优的解法）。

### Q3 二叉树的层序遍历。

**考察点**：广度优先搜索、队列。

**思路**：用队列逐层处理，每一层开始时记录队列的长度，就是这一层的节点数。

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode(int val) {
        this.val = val;
    }
}

class LevelOrder {
    List<List<Integer>> traverse(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) {
            return result;
        }
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            int size = queue.size();
            List<Integer> level = new ArrayList<>(size);
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            result.add(level);
        }
        return result;
    }
}
```

**复杂度**：时间 O(n)，空间 O(n)。

**Agent 场景中的对应**：按层级遍历文档的标题结构，做分层分块；按层级展示多 Agent 的调用树。

**追问**：*如何按之字形顺序输出？* 奇数层正序、偶数层逆序，可以在每层结束后按层号反转列表。

**减分回答**：分不清广度优先和深度优先。

### Q4 二叉树中两个节点的最近公共祖先。

**考察点**：递归的设计。

**思路**：在左右子树中分别查找。如果两边都找到了，当前节点就是最近公共祖先；否则返回找到的那一边。

```java
class LowestCommonAncestor {
    TreeNode find(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) {
            return root;
        }
        TreeNode left = find(root.left, p, q);
        TreeNode right = find(root.right, p, q);
        if (left != null && right != null) {
            return root;
        }
        return left != null ? left : right;
    }
}
```

**复杂度**：时间 O(n)，空间 O(h)（h 为树的高度）。

**Agent 场景中的对应**：在组织架构或权限树中，找出两个部门共同的上级，用于判断数据的可见范围。

**追问**：*如果是二叉搜索树呢？* 可以利用大小关系：两个节点都比当前节点小就去左子树，都大就去右子树，否则当前节点就是答案。

**减分回答**：分别记录两个节点到根的路径再比较（可以做，但空间开销更大）。

### Q5 无重复字符的最长子串。

**考察点**：滑动窗口。

**思路**：用两个指针维护一个没有重复字符的窗口；右指针扩展窗口，遇到重复字符时把左指针移动到该字符上一次出现位置的后面。

```java
class LongestUniqueSubstring {
    int length(String s) {
        Map<Character, Integer> lastIndex = new HashMap<>();
        int best = 0;
        int left = 0;
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            Integer previous = lastIndex.get(c);
            if (previous != null && previous >= left) {
                left = previous + 1;
            }
            lastIndex.put(c, right);
            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}
```

**复杂度**：时间 O(n)，空间 O(字符集大小)。

**Agent 场景中的对应**：滑动窗口的思想与限流中的滑动窗口计数、上下文的滑动窗口裁剪是同一类问题。

**追问**：*如果要求窗口中最多包含 K 种不同的字符呢？* 用一个计数表记录窗口内每种字符的数量，种类超过 K 时收缩左边界。

**减分回答**：枚举所有子串再判断是否重复（O(n³) 或 O(n²)）。

### Q6 编辑距离。

**考察点**：动态规划。

**思路**：`dp[i][j]` 表示把 `a` 的前 i 个字符变成 `b` 的前 j 个字符需要的最少操作数。
字符相同时 `dp[i][j] = dp[i-1][j-1]`；否则取插入、删除、替换三种操作中的最小值再加 1。

```java
class EditDistance {
    int distance(String a, String b) {
        int m = a.length();
        int n = b.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (a.charAt(i - 1) == b.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = 1 + Math.min(dp[i - 1][j - 1], Math.min(dp[i - 1][j], dp[i][j - 1]));
                }
            }
        }
        return dp[m][n];
    }
}
```

**复杂度**：时间 O(mn)，空间 O(mn)，可以优化为只保留两行，空间降到 O(n)。

**Agent 场景中的对应**：模糊匹配用户输入的商品名或指令、判断两段文本的字面相似度、评测时比较输出与期望答案的差异。

**追问**：*编辑距离和语义相似度有什么区别？* 编辑距离只看字符层面的差异，“退货”和“退款”只差一个字，但含义不同；
语义相似度需要借助 Embedding。

**减分回答**：说不出状态定义和转移方程。

### Q7 岛屿数量。

**考察点**：图的遍历（深度优先或广度优先）。

**思路**：遍历网格，遇到陆地就计数加一，并用深度优先搜索把与它相连的陆地全部标记为已访问。

```java
class NumberOfIslands {
    int count(char[][] grid) {
        int islands = 0;
        for (int r = 0; r < grid.length; r++) {
            for (int c = 0; c < grid[r].length; c++) {
                if (grid[r][c] == '1') {
                    islands++;
                    sink(grid, r, c);
                }
            }
        }
        return islands;
    }

    /** 用显式栈代替递归，避免网格很大时栈溢出 */
    private void sink(char[][] grid, int row, int col) {
        Deque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[] {row, col});
        grid[row][col] = '0';
        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!stack.isEmpty()) {
            int[] cell = stack.pop();
            for (int[] d : directions) {
                int r = cell[0] + d[0];
                int c = cell[1] + d[1];
                if (r >= 0 && r < grid.length && c >= 0 && c < grid[r].length && grid[r][c] == '1') {
                    grid[r][c] = '0';
                    stack.push(new int[] {r, c});
                }
            }
        }
    }
}
```

**复杂度**：时间 O(行数 × 列数)，最坏情况下空间 O(行数 × 列数)。

**Agent 场景中的对应**：计算知识图谱或文档引用关系中的连通分量，找出彼此孤立的知识簇。

**追问**：*能否用并查集解决？* 可以。把相邻的陆地合并到同一个集合，最后统计集合的数量；并查集更适合需要动态添加陆地的变种题。

**减分回答**：递归实现不考虑栈溢出，也说不出复杂度。

### Q8 课程表：判断能否完成所有课程（拓扑排序）。

**考察点**：有向图、拓扑排序、环检测。

**思路**（Kahn 算法）：统计每个节点的入度，把入度为 0 的节点放入队列；每取出一个节点，就把它指向的节点的入度减一，
减到 0 的加入队列。最后处理过的节点数等于总数，说明没有环。

```java
class CourseSchedule {
    /** prerequisites[i] = {a, b} 表示学习 a 之前必须先学习 b */
    boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        int[] inDegree = new int[numCourses];
        for (int[] edge : prerequisites) {
            graph.get(edge[1]).add(edge[0]);
            inDegree[edge[0]]++;
        }
        Deque<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }
        int visited = 0;
        while (!queue.isEmpty()) {
            int course = queue.poll();
            visited++;
            for (int next : graph.get(course)) {
                if (--inDegree[next] == 0) {
                    queue.offer(next);
                }
            }
        }
        return visited == numCourses;
    }
}
```

**复杂度**：时间 O(V + E)，空间 O(V + E)。

**Agent 场景中的对应**：工作流中节点的依赖关系检查（编排平台保存流程时检测是否有环）、多个子任务的执行顺序规划、
确定可以并行执行的任务（同一批入度为 0 的节点）。

**追问**：*如何输出一个合法的学习顺序？* 按出队的顺序记录节点即可。

**减分回答**：不知道如何检测有向图中的环。

### Q9 前 K 个高频元素。

**考察点**：哈希表加堆。

**思路**：先用哈希表统计频次，再用大小为 K 的最小堆（按频次排序）保留频次最高的 K 个。

```java
class TopKFrequent {
    List<String> topK(List<String> words, int k) {
        Map<String, Integer> counts = new HashMap<>();
        for (String word : words) {
            counts.merge(word, 1, Integer::sum);
        }
        PriorityQueue<Map.Entry<String, Integer>> heap =
            new PriorityQueue<>(Map.Entry.comparingByValue());
        for (Map.Entry<String, Integer> entry : counts.entrySet()) {
            heap.offer(entry);
            if (heap.size() > k) {
                heap.poll();
            }
        }
        List<String> result = new ArrayList<>();
        while (!heap.isEmpty()) {
            result.add(heap.poll().getKey());
        }
        Collections.reverse(result);
        return result;
    }
}
```

**复杂度**：时间 O(n log K)，空间 O(n)。

**Agent 场景中的对应**：统计知识盲区中最常见的未命中问题、最常被调用的工具、最高频的用户意图。

**追问**：*数据量非常大、无法全部放进内存怎么办？* 先按哈希把数据分片到多个文件，每个分片分别统计并取前 K，最后合并；
或者使用 Count-Min Sketch 这类近似算法做流式统计。

**减分回答**：统计后对全部元素排序（可以做，但说不出堆的解法）。

### Q10 合并区间。

**考察点**：排序与贪心。

**思路**：按区间的起点排序，依次遍历；当前区间与结果中最后一个区间重叠时合并，否则直接加入结果。

```java
class MergeIntervals {
    int[][] merge(int[][] intervals) {
        if (intervals.length == 0) {
            return new int[0][];
        }
        int[][] sorted = intervals.clone();
        Arrays.sort(sorted, Comparator.comparingInt(a -> a[0]));
        List<int[]> result = new ArrayList<>();
        int[] current = sorted[0].clone();
        for (int i = 1; i < sorted.length; i++) {
            if (sorted[i][0] <= current[1]) {
                current[1] = Math.max(current[1], sorted[i][1]);
            } else {
                result.add(current);
                current = sorted[i].clone();
            }
        }
        result.add(current);
        return result.toArray(new int[0][]);
    }
}
```

**复杂度**：时间 O(n log n)，空间 O(n)。

**Agent 场景中的对应**：多个敏感词命中的位置有重叠时，合并成需要打码的区间；合并引用来源在原文中的高亮范围；合并时间段。

**追问**：*如何插入一个新区间并保持有序、不重叠？* 先加入所有在新区间之前的区间，再合并与新区间重叠的部分，最后加入剩余的区间，复杂度 O(n)。

**减分回答**：不排序直接两两比较。

### Q11 在旋转过的有序数组中查找目标值。

**考察点**：二分查找的变体。

**思路**：每次二分后，左右两半中至少有一半是有序的；判断目标值是否落在有序的那一半中，决定往哪边继续查找。

```java
class SearchRotatedArray {
    int search(int[] nums, int target) {
        int low = 0;
        int high = nums.length - 1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (nums[mid] == target) {
                return mid;
            }
            if (nums[low] <= nums[mid]) {
                // 左半部分有序
                if (target >= nums[low] && target < nums[mid]) {
                    high = mid - 1;
                } else {
                    low = mid + 1;
                }
            } else {
                // 右半部分有序
                if (target > nums[mid] && target <= nums[high]) {
                    low = mid + 1;
                } else {
                    high = mid - 1;
                }
            }
        }
        return -1;
    }
}
```

**复杂度**：时间 O(log n)，空间 O(1)。

**追问**：*为什么中点要写成 `low + (high - low) / 2`？* 避免 `low + high` 溢出整数范围。

**减分回答**：直接顺序遍历（O(n)）。

### Q12 实现前缀树（Trie），支持插入、查找完整单词和前缀查询。

**考察点**：树形数据结构的设计。

**思路**：每个节点保存子节点的映射，以及“是否是一个单词的结尾”的标记。

```java
class Trie {

    private static final class Node {
        final Map<Character, Node> children = new HashMap<>();
        boolean end;
    }

    private final Node root = new Node();

    void insert(String word) {
        Node node = root;
        for (char c : word.toCharArray()) {
            node = node.children.computeIfAbsent(c, k -> new Node());
        }
        node.end = true;
    }

    boolean search(String word) {
        Node node = find(word);
        return node != null && node.end;
    }

    boolean startsWith(String prefix) {
        return find(prefix) != null;
    }

    private Node find(String text) {
        Node node = root;
        for (char c : text.toCharArray()) {
            node = node.children.get(c);
            if (node == null) {
                return null;
            }
        }
        return node;
    }
}
```

**复杂度**：插入和查找都是 O(单词长度)。

**Agent 场景中的对应**：输入联想（根据前缀推荐常见问题）；敏感词匹配的基础结构，在 Trie 上加上失败指针就是 Aho-Corasick 自动机，
可以一次扫描匹配所有关键词（见 [项目第 05 期 Q3](../05-安全护栏与治理中间件.md)）。

**追问**：*Trie 和 Aho-Corasick 有什么区别？* 用 Trie 匹配多个关键词时，需要从文本的每个位置重新开始匹配；
Aho-Corasick 通过失败指针在匹配失败时直接跳到可能的位置，一次扫描就能完成，时间复杂度与文本长度线性相关。

**减分回答**：用 `HashSet` 保存所有前缀，内存浪费严重。

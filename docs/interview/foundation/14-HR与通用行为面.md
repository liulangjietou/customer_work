# 基础补全第 14 期 · HR 与通用行为面

> **本期结论**：HR 面和行为面没有标准答案，面试官看的是三件事：动机是否清晰、表达是否真诚可信、与岗位和团队是否匹配。
> 本期给出的是答题思路和结构，不是可以照背的台词。所有回答都应该基于真实经历，编造的经历在追问下很容易露馅。
>
> 答题通用原则：先给结论，再给理由和事实；多讲具体的事，少讲空泛的形容词；不贬低前公司和同事。
>
> 题量 12。

---

### Q1 请做一个自我介绍。

**考察点**：表达的结构；与岗位的匹配度。

**答题思路**（控制在 2 分钟左右）

1. **基本信息**：一句话说明自己的方向和年限，例如“做了 6 年 Java 后端，最近两年专注于 Agent 应用开发”。
2. **与岗位最相关的经历**：挑一到两个项目，说明规模、自己的角色、解决的关键问题和结果（尽量有数据）。
3. **能力亮点**：与 JD 对应，例如“熟悉 RAG 和工具调用的工程化，做过评测体系和成本治理”。
4. **求职动机**：为什么对这个岗位感兴趣。

- **项目经历可以这样组织**：一句话介绍项目 → 我负责的部分 → 遇到的最难的问题 → 怎么解决 → 结果（见 [项目第 01 期 Q1](../01-项目全景与架构设计.md)）。

**追问**：面试官通常会从自我介绍中挑一个点深入追问，所以提到的每个技术点都要能讲得出细节。

**减分回答**：照着简历逐条念；讲了很多与岗位无关的经历；时间过长。

### Q2 你为什么离开上一家公司？

**考察点**：离职动机是否合理、是否存在稳定性风险。

**答题思路**

- **讲“追求什么”，而不是“逃避什么”**：例如“希望在 Agent 方向深入发展，上一家公司的业务在这个方向的投入有限”。
- **真实、简洁**：一两个主要原因即可，不需要展开很多细节。
- **与新岗位建立联系**：说明新岗位能满足自己的哪些发展诉求。
- **如果确实有客观原因**（例如业务调整、团队解散），可以如实说明，保持客观、不带情绪。

**追问**：*如果新公司也出现类似的情况，你会怎么办？* 说明自己会先尝试解决问题、与团队沟通，而不是一有问题就离开。

**减分回答**：抱怨前公司、领导或同事；说“钱太少”作为唯一的理由；前后回答相互矛盾。

### Q3 你为什么要从传统后端转向 Agent 开发？

**考察点**：转型的动机和准备是否充分。

**答题思路**

- **动机**：行业趋势加上个人兴趣，最好有具体的触发点，例如“在项目中接入大模型后，发现工程化的问题很有挑战”。
- **已经做的准备**：做过的项目、学习的内容、解决过的具体问题，用事实证明投入，而不只是“感兴趣”。
- **原有能力的迁移**：后端的高并发、分布式、稳定性经验，在 Agent 的生产化中非常重要，这是转型的优势。
- **仍然需要补足的地方**：坦诚说明，并说明计划。

**追问**：*你觉得 Agent 开发和传统后端开发最大的区别是什么？* 模型的输出不确定，需要用评测、护栏、兜底来管理这种不确定性，
工程上的思维方式因此不同。

**减分回答**：“因为 AI 很火，工资高”。

### Q4 你未来 3～5 年的职业规划是什么？

**考察点**：目标是否清晰、与岗位是否匹配、是否稳定。

**答题思路**

- **短期（1～2 年）**：在岗位上做出成果，例如深入掌握 Agent 的工程化、负责某个核心模块。
- **中长期（3～5 年）**：成为某个方向的技术专家，或者承担技术负责人的角色。
- **与公司的发展结合**：说明自己的规划如何为团队和业务创造价值。
- **保持务实**：规划要具体、可行，同时表达出愿意根据实际情况调整。

**追问**：*你更倾向于技术专家路线还是管理路线？* 真实表达自己的倾向，并说明理由；也可以表达先深耕技术，再视情况承担更多的团队职责。

**减分回答**：“没有想过”；或者目标与岗位毫不相关（例如计划很快转行或创业）。

### Q5 你的期望薪资是多少？

**考察点**：期望是否合理；沟通方式。

**答题思路**

- **提前做功课**：了解目标城市、岗位级别的市场行情，以及自己当前的薪资结构。
- **给出一个合理的范围**，并说明依据（当前的薪资、市场行情、岗位的职责）。
- **关注整体的待遇**：基本工资、奖金、股票、福利、成长空间，而不只是一个数字。
- **保持弹性**：表达出愿意在了解岗位的具体职责和整体待遇后进一步沟通。
- **如实提供当前的薪资**：背景调查可能会核实，虚报有风险。

**追问**：*如果我们给的薪资低于你的期望，你会怎么考虑？* 说明自己会综合考虑岗位的发展空间和整体待遇，同时也可以说明自己最看重的是什么。

**减分回答**：没有准备，随口说一个数字；或者态度强硬、没有任何沟通的余地。

### Q6 你最大的缺点是什么？

**考察点**：自我认知和改进能力。

**答题思路**

- **说一个真实的、与工作相关的、不影响核心能力的缺点**。
- **说明已经采取的改进措施和效果**，体现自我提升的能力。
- **示例方向**：“以前在技术方案上容易追求完美，导致交付变慢。现在会先和需求方明确优先级和最小可用的范围，分阶段交付。”

**追问**：*能举一个这个缺点带来问题的具体例子吗？* 准备一个真实的例子，并说明后来是怎么改进的。

**减分回答**：说一个其实是优点的“缺点”（例如“太追求完美”却讲不出任何负面影响）；或者说出与岗位要求直接冲突的缺点。

### Q7 讲一次你和同事或上级意见不一致的经历，你是怎么处理的？

**考察点**：沟通与协作能力。

**答题思路**（STAR 结构）

1. **情境**：什么项目，分歧是什么（最好是技术方案的分歧）。
2. **行动**：先理解对方的出发点；用数据和事实支持自己的观点（例如做原型验证、给出评测数据）；寻找双方都能接受的方案。
3. **结果**：最终的决定和效果。
4. **反思**：从中学到了什么。

- **重点**：体现对事不对人、用数据说话、以团队目标为重。即使最后没有采用自己的方案，也要说明自己如何支持团队的决定。

**追问**：*如果事后证明你的方案是对的，你会怎么做？* 客观地复盘，关注如何改进决策过程，而不是证明自己是对的。

**减分回答**：说自己从来没有和别人产生过分歧；或者把责任全部推给对方。

### Q8 讲一次失败的经历。

**考察点**：责任感与从失败中学习的能力。

**答题思路**

1. **真实的失败**：例如一次线上事故、一个没有达到预期的项目。
2. **自己的责任**：坦诚说明自己在其中的问题。
3. **补救措施**：当时是如何处理和止损的。
4. **根因和改进**：分析根本原因，以及之后建立了什么机制来避免再次发生（例如增加测试、监控、流程）。

- **Agent 方向的素材**：例如某个能力只在一条链路上生效，导致线上问题没有被发现；后来建立了统一的装配入口和结构化测试
  （见 [项目第 08 期 Q7](../08-模型路由成本评测与系统设计.md)）。

**追问**：*如果再来一次，你会怎么做？* 说出具体的不同做法。

**减分回答**：说自己没有失败过；或者讲的失败完全是别人的原因。

### Q9 你怎么看待加班？

**考察点**：工作态度与岗位期望的匹配。

**答题思路**

- **表达对工作负责的态度**：遇到紧急的线上问题、关键的上线节点，愿意投入必要的时间。
- **强调效率**：更倾向于通过合理的规划和提升效率来减少不必要的加班。
- **可以了解团队的实际情况**：在合适的时候询问团队的工作节奏，判断是否与自己的期望匹配。

**追问**：*如果长期需要加班，你能接受吗？* 如实表达自己的想法，这关系到入职后双方是否满意。

**减分回答**：明显不真诚的回答（例如“我特别喜欢加班”），或者完全拒绝。

### Q10 你为什么选择我们公司？

**考察点**：求职的诚意和对公司的了解程度。

**答题思路**

- **提前了解公司**：业务方向、产品、在 AI 方向上的布局、技术团队的公开分享。
- **从三个角度回答**：公司的业务和发展前景；岗位与自己的经验和规划的匹配；团队和技术氛围。
- **具体**：提到具体的产品或技术方向，而不是泛泛地说“公司很有名”。

**追问**：*你还在面试其他哪些公司？* 可以如实说明大致的方向，不需要透露具体的细节；强调自己对这个岗位的兴趣。

**减分回答**：对公司的业务一无所知；回答适用于任何一家公司。

### Q11 如果同时拿到多个 offer，你会怎么选择？

**考察点**：决策的依据与稳定性。

**答题思路**

- **说明自己的判断标准**：业务方向和发展前景、岗位能获得的成长、团队和上级、整体待遇、工作地点和工作节奏。
- **体现理性和稳定**：不是只看薪资，而是看长期的发展。
- **表达对当前岗位的兴趣**：说明这个岗位在哪些方面符合自己的标准。

**追问**：*如果另一家公司给的薪资更高，你会怎么选？* 说明自己会综合比较，重点考虑长期的发展，而不是只看薪资的差距。

**减分回答**：拿 offer 作为压价的筹码，态度强硬。

### Q12 你有什么问题想问我们？

**考察点**：对岗位的思考深度和真实兴趣。

**答题思路**（选择两三个真正关心的问题）

- **关于岗位**：这个岗位目前最重要的目标是什么？入职后的前三个月希望完成哪些事情？
- **关于团队和技术**：团队的规模和分工？Agent 目前落地在哪些业务场景？评测和上线的流程是怎样的？主要的技术挑战是什么？
- **关于成长**：团队如何进行技术分享和人才培养？
- **面向技术面试官**：可以问一个与面试中讨论过的技术问题相关的深入问题。

**追问**：面试官的回答往往能帮助判断这个岗位是否适合自己，要认真听并适当追问。

**减分回答**：“没有问题”；或者在第一轮就只问薪资和假期。

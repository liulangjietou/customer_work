# Agent 开发 · 基础补全篇（Java 后端基础 / 手写代码 / 专题深入）

> 共 **14 期、164 题**，补齐前三篇没有覆盖或只零散提到的内容：
> JD 中明确要求的 Java 后端基础（集合与并发、JVM 与 Spring、MySQL / Redis / MQ、微服务与云原生）、计算机网络与操作系统、
> 手写代码题与通用算法题、Python 基础与生态、评测与观测工具实操、HR 与通用行为面，
> 以及提示词工程、LLM 原理、工作流编排、向量数据库四个专题。
>
> 格式与其他三篇一致：每题包含**考察点**、**参考回答**、**追问**、**减分回答**。第 08、11 期的代码题给出 Java 17 参考实现，已编译并通过示例用例；
> 第 12 期的 Python 示例已在真实的库版本下运行验证；第 14 期给出的是答题思路而不是台词。
> Java 基础题都补充了“在 Agent 服务中的体现”，便于把八股文和实际场景结合起来回答。

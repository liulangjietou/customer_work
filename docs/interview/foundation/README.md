# Agent 开发 · 基础补全篇（Java 后端基础 / 手写代码 / 专题深入）

> 共 **9 期、104 题**，补齐前三篇没有覆盖或只零散提到的内容：
> JD 中明确要求的 Java 后端基础（集合与并发、JVM 与 Spring、MySQL / Redis / MQ、微服务与云原生）、手写代码题，
> 以及提示词工程、LLM 原理、工作流编排、向量数据库四个专题。

> 格式与其他三篇一致：每题包含**考察点**、**参考回答**、**追问**、**减分回答**；第 08 期的手写代码题给出 Java 17 的参考实现。

## 二、和项目实战篇怎么配合使用

- **面试官**：先用通用题判断基础是否扎实，再用项目实战篇的题目深挖候选人的项目经历。
  通用题回答得好、项目题回答不出细节，说明可能只是背过八股文。
- **候选人**：回答通用题时，尽量用项目里的真实例子来佐证，例如讲幻觉时提到越权承诺检测，
  讲工具设计时提到工具面的 token 成本。这比只背概念更有说服力。

# 本地排障速查

配合 `scripts/dev-health-check.sh` 使用。现象 → 先查什么 → 怎么处理。

## 构建与测试

| 现象 | 原因 | 处理 |
|---|---|---|
| Maven 卡在下载、0% CPU | 全局 `settings.xml` 内网镜像 + 只传 `-s` 没传 `-gs` | 同时传 `-gs scripts/settings-central-direct.xml -s scripts/settings-central-direct.xml` |
| `Could not create local repository` | settings 里写死了他人本机 `localRepository` | 用仓库根 `settings-central-direct.xml` 或改成本机路径 |
| 改依赖后编译过、运行怪 | 增量编译不刷新 classpath | `mvn clean ...` |
| `RedisSessionPersistenceTest` 失败 | 本机 Redis 无密码，测试期望 `123456` | 全量加 `-Dtest='!RedisSessionPersistenceTest'` 或给 Redis 设密码 |
| admin 大量 Error / CommunicationException | MySQL 或 MinIO 未起 | `docker start mysql_db_low_case minio-server` 后重跑 |
| starter skip 从个位数飙到 100+ | 同上，门控测试连不上库 | 先起容器再判回归 |
| 两个 Maven 同时跑假编译失败 | 双进程写同一 `target/` | 只留一个全量；异常时 `mvn clean` |
| CI 在 MinIO 步骤就红、0 测试 | 镜像 manifest 失效 | 看 CI 日志哪一步；非代码回归（见 `CLAUDE.md`） |

## 后台 admin-server

| 现象 | 原因 | 处理 |
|---|---|---|
| 登录 500 / 登录不了 | Redis 不可达，Sa-Token fail-closed | 起 Redis；应急 `ADMIN_SATOKEN_REDIS_PERSISTENT=false`（仅 dev） |
| Flyway checksum / failed migration | 手工改过已执行迁移或 history 脏 | 勿随意 `repair`；对齐库版本后 baseline（见 `CLAUDE.local.md`） |
| 注册发不出验证码 | 未配 SMTP | 注释里 SMTP 示例在 `scripts/run-admin-server-dev.sh` |
| IDE 启动缺变量 | Run Configuration 不继承 shell export | 对照 dev 脚本补 `ADMIN_MYSQL_PASSWORD` 等 |

## 客服 app-server

| 现象 | 原因 | 处理 |
|---|---|---|
| H5 能连但无智能回复 | 模型 Key 未配、配额耗尽 | 查 `docs/功能与配置全量参考.md` 与环境变量 |
| WS 重连后缺消息 | 客户端未补拉历史 | 数据在库；前端 `Chat.vue` 重连逻辑（见历史批次说明） |

## 端口冲突

| 端口 | 默认占用方 |
|---|---|
| 3306 | 本项目 MySQL；kb-rag 等可改 13306 |
| 9000 | 本项目 MinIO；kb-rag 已避让 19000 |
| 8080/8082/5174/5175 | 各服务固定默认，可用 yml/ env 覆盖 |

## 一键快检与分层回归

```bash
chmod +x scripts/dev-health-check.sh scripts/run-focused-tests.sh scripts/run-frontend-checks.sh scripts/pre-pr-grep.sh

./scripts/dev-health-check.sh --strict
./scripts/pre-pr-grep.sh
./scripts/run-focused-tests.sh
./scripts/run-frontend-checks.sh   # 需 Node；首次会 npm install
```

## 第一轮自审关注点（改代码前扫一眼）

- **并发**：会话 `SessionLock`、Reactor 链上的锁释放、`KeyedSerialExecutor` 等同 key 串行  
- **租户**：异步入口是否恢复 `TenantContext`；缺上下文应 fail-closed  
- **流式**：改 `AgentResultEvent` 用户可能看不到；流式闸门要在 `TextBlockDelta` 生命周期内  
- **跨库**：admin 是否绕过 `CustomerWorkFacade`  
- **安全**：工具/MCP 是否新增数据出口；敏感配置是否走 `SecretRef`
